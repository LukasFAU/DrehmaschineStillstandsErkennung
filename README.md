# Brief description
This project serves to create a Streamlit app that makes it possible to recognise the standstill of a lathe and provide an estimate of whether this was a planned or unplanned standstill.

# Detailed description
This project allows you to create a Streamlit app. This makes it possible to upload images or videos up to a size of 200 MB. After uploading, the image recognition starts automatically. To speed up processing, a factor can be selected that specifies how many images should be skipped. The minimum confidence for recognising the individual classes can also be specified.
As soon as the image recognition is complete, two graphics and a button to download the image recognition results as a CSV file are displayed.
The first graphic shows the recognised classes. The second graphic shows whether the programme classifies the standstill of the lathe as a planned or unplanned stop.
